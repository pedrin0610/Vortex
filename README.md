# Vortex Digital

Site institucional responsivo feito com HTML, CSS e JavaScript puro.

## Como executar
1. Extraia a pasta do projeto.
2. Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Personalização obrigatória antes de publicar
- `script.js`: altere `WHATSAPP_NUMBER` para seu número real, com código do país + DDD + número, somente dígitos.
- `index.html`: troque nome, e-mail, textos, serviços, projetos-conceito e informações da agência.
- O e-mail `contato@vortexdigital.com.br` é demonstrativo; substitua pelo seu endereço.
- Os projetos do portfólio são conceitos visuais fictícios. Não os apresente como clientes reais.

## Observações
- O formulário abre uma conversa no WhatsApp com os dados preenchidos; não armazena nem envia dados para um servidor.
- A fonte é carregada do Google Fonts; sem internet, o navegador usa fontes alternativas.
- Para publicar, envie os três arquivos (`index.html`, `style.css`, `script.js`) para sua hospedagem ou serviço de hospedagem estática.
